# BuildTwin on Replit

BuildTwin is a single-page construction progress dashboard built with TanStack Start, React, and TypeScript.

## Run locally or in Replit

- Install the project dependencies with `bun install`.
- Start the development server with `bun run dev -- --host 0.0.0.0 --port 5000`.
- Run the test suite with `bun run test`.
- Create a production build with `bun run build`.

The Replit web preview uses port 5000. The dashboard currently runs as a local demo: project, scan, schedule, and chat data are sample values held in the UI; chat replies are simulated and are not saved to a project.
